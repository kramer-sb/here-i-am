## Specializing in Linux, with [HackRange](https://www.hackrange.com/learn/courses/specializing-in-linux-course.html)

*Get genuinely good at Linux by living in it. Working across Ubuntu and RHEL, you will learn the file system, the shell, scripting with Python, and the desktop the way you actually use them day to day. Every lesson is hands-on in a real environment, with the safe habits of a professional built in from day one, so you come out comfortable on any Linux box and ready for whatever you run next. You will be well-rounded in Debian and RHEL which are the most popular and widley used distros!*

### Setting Up Kali, Lessons 5-8
Installing Kali, basic commands, updating, etc. 

### The Graphical Desktop, Lessons 9-12 
xfce, menu, panel, terminals, keyboard shortcuts, more

### Meet the Terminal and the Shell, Lessons 13-16
Terminal, shell, console, tty, bash & besties, anatomy of a command, help, etc.

### The Linux File System, Lessons 17-20
Filesystem hierarchy, absolute paths, cd, hidden files, etc.
- `pwd` - use this to make sure you are where you think you are! 
- tab key. It really works. Use it!

### Working with Files and Directories, Lessons 21-25
Listing & navigating, creating & removing, copying & moving & renaming
- `ls -lah` - How I live now!
- `tree`
- `ls` before you delete & `pwd` to make sure you know where you are

### Viewing and Editing Files, Lessons 26-30
Reading files, looking inside them, edit with nano, dabble in vim
- make a copy first of any important file before you edit it: `cp /etc/ssh/ssh_config /etc/ssh/ssh_config.bak`
- examine before you trust; extensions lie; `file` does not and it, with `strings` and `xxd`, are free to look
- `nano` is easy but not always installed
- `vimtutor` to learn how to use vim confidently; is installed by default
